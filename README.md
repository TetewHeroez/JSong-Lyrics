# 🎵 JSong Lyrics

Kumpulan lirik lagu-lagu Jepang favorit saya, lengkap dengan **furigana** (cara baca kanji) dan **terjemahan bahasa Indonesia**.

## ✨ Tujuan

Saya membuat proyek ini sebagai media belajar **bahasa Jepang** — terutama **kanji** dan **kotoba** (kosakata) — melalui lagu-lagu Jepang yang saya sukai. Dengan membaca lirik sambil mendengarkan lagunya, belajar jadi lebih menyenangkan dan mudah diingat!

## 🎶 Fitur

- 📖 Lirik asli dalam bahasa Jepang
- 🔤 Furigana (cara baca) di setiap kanji — bisa ditampilkan per kata atau sekaligus
- 🇮🇩 Terjemahan bahasa Indonesia di setiap baris
- 🎧 Pemutar Spotify / YouTube terintegrasi
- 📱 Tampilan responsif untuk desktop dan mobile
- 💾 Otomatis menyimpan posisi terakhir (lagu & scroll)
- 🔠 Pengaturan ukuran font
